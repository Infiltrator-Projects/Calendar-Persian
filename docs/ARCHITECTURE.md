# Persian Solar Hijri Calendar

Persian chronology and formatting remain provider-owned. Public ABI, generic checked arithmetic and civil/JDN coordinates come from the exact Common 1.19.87 submodule at `b888a541baf50728016e2d4d1bcbafc9455bd684`, compiled and linked rather than copied. The provider uses C++20 chronology with C11 helpers and a stable C ABI. The native network installer obtains the pinned sources, verifies their identities and builds locally. Provider and accuracy tests are mandatory. See [packaging](PACKAGING.md) for the distribution contract.
