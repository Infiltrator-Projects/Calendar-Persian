# Persian Solar Hijri Calendar

Persian chronology and formatting remain provider-owned. Public ABI, generic checked arithmetic and civil/JDN coordinates come from the exact Common 1.19.89 submodule at `de173264da56ac001e46bb9d2b2ca651706ac10b`, compiled and linked rather than copied. The provider uses C++20 chronology with C11 helpers and a stable C ABI. The native network installer obtains the pinned sources, verifies their identities and builds locally. Provider and accuracy tests are mandatory. See [packaging](PACKAGING.md) for the distribution contract.
