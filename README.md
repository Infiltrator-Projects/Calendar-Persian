## Illustrated user guide

The installed package contains only this calendar's `.so` and an illustrated `.pdf` for ordinary readers. Developer documents stay in GitHub; native build provenance stays in Debian control metadata. The reproducible PDF is generated from `docs/GUIDE.json`.


**Historical scope/accuracy:** Arithmetic Solar Hijri rules provide dates without reconstructing every historically observed Persian calendar reform.
The native RUN downloads the exact provider commit and pinned Common submodule, verifies their identities and builds locally. No source or binary payload is embedded.
